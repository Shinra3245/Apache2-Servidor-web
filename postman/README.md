# Colección Postman — API V2

1. Importar `Autenticacion_API_V2.postman_collection.json` en Postman Desktop
   o en la extensión Postman de Visual Studio Code.
2. Abrir las variables de la colección y escribir la contraseña académica
   proporcionada en el reporte dentro de `password`.
3. Ejecutar las solicitudes en el orden indicado.
4. La primera petición guarda automáticamente el token Bearer en
   `access_token`.

La contraseña y los tokens no se guardan en Git.
